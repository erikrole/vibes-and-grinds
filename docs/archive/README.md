state of the project at the time they were written and may not match the
shipped product:

  the plan is preserved for context.

  The implementation was reverted in `5a7d264` and is not currently planned.

- **VEST_TRACKER_IDEAS.md** — brainstorm doc for vest-tracker styling and copy.

Don't treat any of these as current. New planning should go in PR
descriptions / issues.
